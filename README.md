# Student Performance Prediction System

## Project Overview
This project predicts a student's Mathematics score using Machine Learning techniques.

The prediction is based on:
- Reading Score
- Writing Score
- Gender
- Lunch Type
- Test Preparation Course

## Objective
The objective of this project is to predict student academic performance and understand the factors affecting student scores.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

## Machine Learning Model
- Linear Regression

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Model Training
5. Model Evaluation
6. Model Deployment using Streamlit

## Dataset
The project uses the Students Performance Dataset.

## Performance Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score
